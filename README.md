# AgriRover

AgriRover is an agricultural rover project combining hardware design, embedded systems, and robotics.

## Project Structure

- **cad/** - CAD models and designs
- **src/** - Source code
- **kicad/** - KiCad circuit designs
- **assets/** - Project assets and resources
- **journal_images/** - Journal documentation images
